# 论坛AI机器人快速启动指南

## 环境确认

1. 论坛后端运行在 `http://localhost:4477`
2. Python虚拟环境已配置

## 快速启动

### 方式一：命令行启动

```bash
cd forum_bot
.\venv\Scripts\activate.bat
python bot.py api
```

### 方式二：分步执行

```bash
# 1. 激活环境
cd forum_bot
.\venv\Scripts\activate.bat

# 2. 创建索引（首次）
python -c "from bot import ForumBot; b = ForumBot(); b.index_all_threads(force=True)"

# 3. 触发回复
python -c "from bot import ForumBot; b = ForumBot(); b.scan_and_reply(limit=10)"
```

## RAG流程说明

```
帖子到来
   │
   ▼
意图判断（关键词+LLM）
   │
   ▼
向量检索（TF-IDF/Chroma）
   │
   ▼
相似度 > 0.9 ?
  ├─ Yes → 直接返回历史答案
  └─ No  → 检索Top-5 → LLM生成回答
   │
   ▼
自动回帖
```

## API端点

- 状态: http://localhost:5000/api/bot/status
- 索引: POST http://localhost:5000/api/bot/index
- 回复: POST http://localhost:5000/api/bot/reply

## 常见问题

- **LLM不工作**: 检查网络和API Key配置
- **无法回帖**: 重启后端确保机器人用户创建成功
- **编码错误**: 使用虚拟环境运行避免编码问题

详细文档见 `RAG_README.md`
